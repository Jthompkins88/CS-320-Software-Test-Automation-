Throughout CS 320, I learned a lot about software testing and why it is important when creating programs. For Project One, I worked on building contact, task, and appointment services using Java. I also used JUnit to test my code and make sure everything worked the way it was supposed to. This gave me a better understanding of how testing can help catch mistakes before they become bigger problems. It also helped me get more comfortable working with Java and figuring out errors when something wasn't working right.

To make sure my code works correctly and is secure, I think it is important to test it throughout the development process instead of waiting until everything is finished. During this course, I tested different situations like entering invalid information, using duplicate IDs, and leaving required fields empty. I learned that just because a program runs doesn't always mean it works the way it should. Testing helps find problems that might have been missed. I also learned that checking user input, reviewing code, and keeping software updated can help prevent security issues.

When it comes to understanding what users need, I think it starts with paying attention to the requirements and making sure I understand what the customer is asking for. In Project One, each service had certain rules I needed to follow, like character limits, required fields, and unique IDs. I had to figure out how to take those requirements and make them work in my code. This showed me how important it is to understand the instructions before jumping straight into programming. Even small details can make a difference in whether a program works correctly.

When designing software, I like to break everything down into smaller steps instead of trying to do the whole project at once. I usually start by looking over the requirements, writing the code for one part, and then testing it before moving on. This approach helped me when working on the contact, task, and appointment services because I could focus on one thing at a time. I also ran into some issues while working with Eclipse and setting up JUnit, which was frustrating at times, but it gave me more practice troubleshooting and figuring out what was causing the problems.

Overall, I feel like this course helped me improve my understanding of software testing and how important it is to building programs that actually work. I still have a lot to learn, but I feel more comfortable using Java, writing JUnit tests, and working through coding errors than I did at the beginning of the course. These are skills I know I'll continue using as I work toward becoming a software engineer.
